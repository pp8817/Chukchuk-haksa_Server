# 3학년 편입생 졸업요건 자동 분석 설계

## 목표

기존 일반 재학생 졸업진단을 유지하면서 3학년 편입생의 총학점, 전공 요건, 지정과목, 등록 학기, GPA, 외국어 인증 및 졸업심사 결과를 조합해 최종 졸업 가능 여부를 계산한다.

## 계산 정책

- 포털 누적 취득학점(`StudentAcademicRecord.totalEarnedCredits`)을 총학점의 단일 기준으로 사용한다.
- 편입 인정과목 코드(`07045`, `07046`, `00111`, `07050`)의 학점은 `recognizedTransferCredits`로만 표시하고 총학점에 중복 합산하지 않는다.
- 편입 인정과목은 전공·교양·일반선택 영역에 배분하지 않는다.
- 학과·입학년도별 기존 영역 요건에서 `전핵`/`전필`/`전취`를 전공필수, `전선`을 전공선택으로 계산한다.
- 3학년 편입생의 전공선택 최소 기준은 기존 전공선택 기준학점의 50%로 계산하며 소수점은 올림한다.
- 일반 교양 영역은 편입생 진단에 포함하지 않는다.
- 지정과목은 실제 유효 이수 과목 코드와 비교하며, 목록 자체의 학점은 취득학점에 합산하지 않는다.
- 외국어 인증과 졸업심사는 값이 없으면 미충족으로 단정하지 않고 수동 확인 상태로 반환한다.

## 수동 확인 정보

포털에서 확인할 수 없는 학생별 값은 기존 학생·졸업 진행 테이블에 분리해 보관한다.

- `students.transfer_registered_semesters`: 편입 후 등록 학기 수.
- `student_graduation_progress.graduation_review_fulfilled`: 졸업논문·시험·작품·실기 등 학과 졸업심사 통과 여부.

포털 동기화는 위 값을 갱신하지 않는다. 수동 값이 없으면 `MANUAL_REVIEW_REQUIRED`, 모두 있으면 자동 계산 결과를 반환한다.

## API 응답

기존 `GET /api/graduation/progress` 응답을 확장한다.

- `analysisType=TRANSFER`를 유지한다.
- `analysisStatus`는 누락된 필수 정보가 있으면 `MANUAL_REVIEW_REQUIRED`, 없으면 `CALCULATED`다.
- `transferProgress.graduationEligible`은 모든 조건이 충족될 때 `true`, 하나라도 충족하지 못하면 `false`, 정보가 부족하면 `null`이다.
- 실제 미충족 조건과 정보 누락 사유를 구분해 반환한다.

## 범위

- 현재 운영 대상인 3학년 편입생만 지원한다.
- 2학년 편입 규칙, 범용 정책 엔진, 과목 대체 승인 자동화는 포함하지 않는다.
